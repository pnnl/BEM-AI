# Learning Contract

OpenStudio AI learning follows this progression:

1. Capture raw events.
2. Distill candidate lessons or assets.
3. Review with a human/modeler gate.
4. Validate with evals.
5. Promote into trusted assets.

Runtime harness learning may create candidates only. Trusted knowledge base,
skill, SDK index, MCP tool, and measure updates require developer pipeline
review and validation.
